# workflow-tester-structure

Static reads of an n8n workflow for workflow-tester: which paths expressions touch, guards, lineage through Set and Code nodes.

Part of [workflow-tester](https://github.com/LudwigGerdes/workflow-tester), which generates and runs contract tests from the payloads a workflow trigger can receive. n8n is the first supported platform. This is an internal workspace library: it is not published on its own, and is bundled into the one published package, `workflow-tester`.
